Core issue-07

URL tokenization is too aggressive for valid separators

The list-expansion helper splits on whitespace, commas, and semicolons everywhere. That keeps the convenience syntax simple, but it also means any legitimate token containing a semicolon can be damaged before yt-dlp sees it.

Evidenceprofessional-video-downloader.ps1:249-266 uses -split '[\s,;]+' after joining the raw inputs.
Why it mattersA parsing rule that is too broad can turn a valid URL list into a set of broken tokens, especially for URLs or query strings that already use semicolons.
